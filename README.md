# 💗 Get Well Soon, Nimra

A cute, pink, playful **Get Well Soon** website made for Nimra.

## ✨ What is included?

- 💗 Pink, soft, kid-friendly design
- 🩹 Interactive magic bandage
- 🧸 Teddy bear virtual hug
- 🍭 Candy delivery
- 🍫 Chocolate delivery
- 🎁 Surprise popup
- 💌 Personal get-well letter
- 🌸 Happy-heart mini game
- 🤲🏻 Dua for complete shifa
- ✨ Little celebration/confetti effects
- 📱 Responsive on phones, tablets, and computers

## 🚀 Run it locally

No installation is required.

Just open `index.html` in a browser.

## 🌐 Put it on GitHub Pages

1. Create a new GitHub repository, for example:
   `get-well-soon-nimra`
2. Upload these three files:
   - `index.html`
   - `style.css`
   - `script.js`
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
6. Click **Save**.
7. GitHub will create your website URL.

There is no backend, database, API key, npm package, or external library. It is completely static and works with GitHub Pages.

## 💕 Personalize it

The easiest place to customize the message is `index.html`.

Search for:
- `Get Well Soon, Nimra!`
- `Dear Nimra,`
- `Someone who wishes you well`

You can replace those with your own words.

You can also edit the playful responses in `script.js`.
